# Virtual-tools
Modding tools for virtual pool 4

Includes:


Asi loader

Freecam mod

Limit ajuster

Tools for converting rooms using python (dust2 as a example) 








Mods installation:






Drag and drop dsound, vp4limits.asi, freecam.asi into your game's folder


Freecam mod usage


move the camera while pressing f4 to activate, use w s a d, Q and E to move around 



For converting rooms read TUTORIAL.MD
